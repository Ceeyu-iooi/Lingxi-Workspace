# 灵犀 DeepSeek 授权桥

支持 Windows 上的 Edge、Chrome。扩展不包含浏览器，不创建浏览器资料目录。

1. 下载公开仓库源码，找到 `browser-extension/deepseek`。
2. 在 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions` 打开开发者模式，选择“加载解压缩的扩展”，选中该目录。
3. 在灵犀供应商管理中选择 DeepSeek Key，点击“获取历史用量”。系统默认浏览器会打开配对页和官方用量页；已经登录时直接使用现有登录，否则在官方页面登录。

授权仅在用户发起的三分钟任务内工作。扩展只读取该次官方请求携带的平台授权，通过一次性配对传回本机；不保存密码、聊天、历史正文或授权凭据。配对信息临时保存在浏览器内存，任务结束清除。灵犀后台核验平台账户与 Key 的归属后保存授权，后续可直接查询。

如果浏览器或官方平台拒绝授权，请重新点击获取，不关闭浏览器安全功能。未安装扩展时，API Key 的余额查询仍可使用。扩展没有自动安装或商店上架承诺。
