# 用量来源及限制

Codex从明确登记的sessions与archived_sessions核验原始token_count证据；累计值不是单次消费，缓存和推理子集不得重复相加。ZCode从可读数据库与日志采集，Harness 逐帧解码 JSONL / 拼接 Zstandard 会话日志，只保留最小用量证据。

ZCode数据库的逻辑请求编号与响应日志的传输请求编号不是同一种身份，trace/turn也会跨多次真实调用复用。已有数据库消费证据时，无法证明独立的响应日志只保留证据，不叠加；覆盖状态中标记未确认重叠。旧版叠加贡献保留退休快照，原始日志证据不删除。归档、删除或恢复外部会话不删除已采集消费，也不会把同一日志重新入账。Harness重复的稳定重试通知只推进一次，真正重试分别保留。

统计范围汇总、跨日累计和平台账单分项均使用精确整数。活动图、范围指标和明细按同一口径核对；没有身份或存在冲突的证据不补数，余额不推算Token。

供应商接入包括DeepSeek、GLM、OpenRouter、New API、Sub2API、硅基流动、Moonshot、MiniMax及自定义余额能力。可用的余额、账单、请求明细和历史Token能力不同；普通Key没有历史接口时显示未知，不能通过余额推算Token。

模型、日期、服务商与Key筛选作用于已采集证据；账户级余额和Key级请求分别展示。相同Key及重复响应去重，账户身份不明确时不合并余额。

Codex API基准估算只使用内置官方价表（`src/server/official-pricing.ts`），每条价格记录官方定价页地址、抓取时间、页面摘要与转录日期：DeepSeek 按官方峰谷规则分别取高峰与谷段单价（北京时间周一至周五 9:00-12:00、14:00-18:00 为高峰，其余时段与周末为半价谷段，取价时刻按消费时间折算上海时区），智谱与 OpenAI 按官方页整价表，缓存读取单独取官方缓存价。历史汇率来自加拿大央行USD/CAD与CNY/CAD交叉换算。官方页未提供数字的模型（如 Codex 内部模型 codex-auto-review）保持未知；更早历史没有官方档时用最近官方档标记为估算并给出缺口天数。缺价、缺少输入/输出/缓存读取或未支持的计费规则时保持未知。全球标准文本档按完整输入选档；缓存写入未报告时按未写入基准情景估算，卡片和明细明确该假设，不含工具附加费。费用图表显示已知部分，缺价部分不计入。Decimal金额与证据关联消费ID，双币种结果受同一筛选管辖。

参考计价不代表订阅实付或供应商扣费。详细记账约定见根目录TOKEN_ACCOUNTING.md；可选提示词AI调用仅在用户点击后发生。

DeepSeek Key 导入后查询余额。点击“一键获取历史用量”可复用已有平台授权；没有有效授权时在独立官方窗口登录，成功后自动匹配对应 Key 并同步。无需复制 cURL。历史按平台返回的粒度展示，不能冒充逐次请求或与 Harness 本地日志叠加。

Codex 首次开启参考计价时准备价格和汇率；每日自动更新按钮控制应用运行时上海时区每天一次同步，关闭后仍能查看缓存费用。左侧刷新按钮更新缺失或变化的证据，并重算受影响消费。ZCode 和 Harness 的真实 Token 继续保留，参考计价已移除。
