# 灵犀安装与首次启动改造计划

执行版本：0.0.31。用户已确认本计划并授权执行。

## 体验与界面

- 原创灵犀标识采用两条相向连接的弧形，统一用于安装器、开屏、登录和侧边栏。
- 参考 DeepSeek Harness 的安装器及开屏：大留白、轻量标题、圆角选择卡、短淡入淡出；纳入项目内部组件库及来源记录。
- 默认浅色；顶栏与浅灰/黑色边沿融合，移除标题文字，保留窗口控制。
- 从主题控件中心以扩张圆形切换主题；减少动画时直接切换。
- 导航采用较大字与图标、灰色选中背景和主题色图标；下拉箭头固定在最右侧。
- 资料位置与空间使用互斥文件分类饼图；数据库载荷为明细，内存缓存单列。

## 安装与首次启动

- 自定义 NSIS 安装界面；新安装默认 <安装路径>\\profile，随安装路径联动；升级保留经核验的旧 Profile，不让残留注册表覆盖新安装默认值。
- 首次启动：约 800ms 原创 Logo 动画 → 选择/创建 Profile → 登录/注册 → Codex、ZCode、Harness 监测 → 供应商用量 API Key → 工作台。
- Profile 确认后启动业务后台；切换 Profile 重新初始化浏览器与后台，不复制、合并资料。
- 监测及 Key 可跳过；账户隔离保存状态，中断后恢复；正常升级不强制引导，设置可重新打开。
- 保留静默安装、更新、差量及卸载资料保护。

## 协作与交付

- 所有长任务采用图形进度条，百分比在旁边；下一行固定“预计剩余时间：xxx”，按实际情况更新，无法估计时说明。
- 五条客观分析要求写入 AGENTS.md；用项目外隔离环境验证，不污染真实账户。
- 验证空间加总、路径与升级、引导恢复、权限和失败、键盘、浅深主题、缩放、窄屏、真实截图。
- 网页验收后构建桌面包；以独立空 Profile 的网页注册、引导与界面复核作为本轮界面验收依据，不再要求实际桌面窗口检查。网页通过不代表安装、升级或卸载已实测，未实测项目分别记录且不阻塞本轮界面交付。
- 分开记录 uiAccepted（网页界面）、payloadVerified（包内资源）、installationAccepted（安装行为）和 desktopAccepted（桌面实测）；取消窗口要求不将 desktopAccepted 改为 true。
- 收尾核验监测开关、跳过和恢复、禁用自动同步的隔离供应商 Key、空间分类、主题、窄屏、字号与键盘；保留恢复基线，按现有授权提交及尝试同步私有仓库、公开网页版和 Releases。
