# 灵犀安装与首次启动实施方案

执行版本：0.0.32。沿用原界面风格，用户已经授权执行；本轮由主代理直接完成。

## 体验与界面

- 原创灵犀标识用于安装器、开屏、Profile首启与侧边栏。
- 参考附件DeepSeek Harness安装器的大留白、圆角与轻量标题；保留本项目白、蓝、灰与深色主题。
- 安装位置和资料位置使用白色圆角框、柔和灰影；“立即安装”为黑底白字圆角按钮；真实进度使用蓝色圆角条。
- 顶栏左侧依次为后退、前进、侧边栏、文件、编辑、视图、帮助、主题切换，右侧为原生窗口控件。650ms圆形主题过渡，减少动画时直接切换。
- 导航灰色选中、正文色文字与主题色图标。主页面外框圆角，总览灰色内套框移除，白色模块卡片保留。
- 设置逐栏目检查保存、放弃、焦点、滚动、字号、浅深色和窄屏。资料饼图互斥统计，内存缓存单列。

## 资料与引导

- React + TypeScript + Vite SPA复用既有交互，Node + TypeScript + SQLite提供共享业务后台；桌面内置Node运行时。
- 一个Profile是一个实例账户。取消登录注册与密码，保留用户名和头像。Profile身份不随改名变化。
- 首次启动：原创Logo → 选择或创建Profile位置 → 填写用户名 → 按需连接Agent监测与供应商Key → 工作台。监测与Key可跳过，中断可恢复。
- 新安装默认安装目录的profile，路径修改时联动；普通升级不得自动清空用户资料。旧账户结构不自动转换，明确提示选择空目录或新版Profile。
- 网页、安装版和便携版各用独立后台与资料定位。便携版不能写入临时解包目录。
- 完整Profile口令加密备份包含凭据；恢复先验证、加密预备份与事务应用。升级与卸载保留资料。
- 更新采用完整下载，保留待安装的新版本，在新后台和页面就绪后清理已使用安装包；便携版提供检查、下载、摘要核验及退出后替换指引。

## 验收与发布

网页、真实Setup、真实桌面与便携窗口均须检查界面和交互，安装、升级、卸载分别记录。构建和网页通过不能替代原生验收，未通过不发布完整版本；用户明确取消本次原生验收时，按指定版本记录取消范围，不标为通过。

候选包在.runtime暂存，不提前替换最后可用版本。正式提升要求与双包摘要匹配的完整验收回执。Release标签和标题仅v版本号，中文说明沿用“新增、改进、修复、下载、首次启动与其他说明”，每次同时提供安装与便携版。

本轮一次性清空本机旧Profile、定位与私有恢复副本，必须在新程序通过验收后执行；保留源码和外部Agent原始日志。这项授权不进入通用升级行为。
