# 安装、首次启动与验收约定

当前实现：0.0.35。产品视觉依据根目录 design.md；历史方案只保留在版本日志。

## 体验

原创 Logo 保持不变。每次真正冷启动展示约 2 秒开屏，完成渐显、轻位移 / 缩放、字标与短暂停留；托盘恢复或第二实例不重播。减少动画保留静态标识与真实等待。

顶栏位置固定，侧栏收起保留 64px 图标栏，约 300ms 横向过渡；主体横向伸缩，纵向保持内容锚点。设置、Profile 卡片、更新弹窗、SwipeToast 与浅深预览遵循同一组件规则。

## Profile 与授权

选择已有 / 新建 Profile → 用户名与头像 → Agent 监测 → 授权只读本机 Codex 凭据 → 供应商 Key → 工作台。身份创建在引导里，不提前露出侧栏与业务主体。可跳过可选连接，步骤保存后推进，中断可恢复。

一个 Profile 对应一个实例，profileId 不随改名变化。桌面默认安装目录下的 profile，可显式选择其他可写目录；路径联动不覆盖已确认的自选 / 升级资料。切换不合并资料，迁移需停写、锁定、备份、校验、原子切换。

不内置官方登录或 Codex CLI，不改写全局凭据；未授权 / 缺失 / 过期独立呈现。没有任何持续有效的清空真实 Profile 授权。

## 安装、更新与卸载

安装 / 卸载保留统一 Logo、白色留白、圆角路径框、黑色主按钮和真实蓝色进度。安装完成有立即启动、完成；卸载成功有说明与完成。失败可退出或重试。

更新使用完整包与摘要核验，用户确认下载及安装。待安装的新包保留；新后台与窗口就绪后清理已使用包，占用时重试。升级与卸载保留 Profile，不递归删除安装根目录或用户资料。

## 验收与预发布

先完成网页数值、交互、视觉与性能回归，再构建 x64 安装 / 便携双包，校验资源、依赖、许可证和摘要。用户已选择本次不运行桌面、安装、升级、卸载 EXE：相应字段均为未验收，不用构建或网页通过替代。

Release 标签与标题使用版本号，不加 v；本次发布 Prerelease。双包先在暂存目录核验，再原子提升，最后保留最新版、一份恢复基线、必要报告及网页运行依赖。
