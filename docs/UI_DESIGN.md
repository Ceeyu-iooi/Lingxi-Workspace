# 灵犀设计规范

## 品牌与基础

原创灵犀标识用两条相向弧形和中央连接点表达默契与协作。SVG 是主资源；应用图标和安装器位图由同一资源生成。蓝色沿用项目强调色，不使用 OpenAI 或 DeepSeek 图形作为灵犀标识。

默认浅色，保留用户已保存的浅色、深色或跟随系统设置。顶栏浅蓝灰与边沿一致，深色顶栏及边沿为黑色；标题文字从可视顶栏移除，应用名称仍用于窗口识别。

## 导航与选择

- 导航行高 44px，默认文字 15px、图标 20px、圆角 12px；字体随用户字号调整。选中背景使用中性灰，文字保留正文色，图标使用强调色。
- 下拉文字和 SVG 箭头分离；箭头区域 20px，固定距右侧 12px，长文字省略。键盘选项、焦点、禁用及多选行为保持。
- 外观预览与保存、放弃逻辑保持一致。显式切换主题使用从触发控件中心展开的 650ms 圆形过渡；首次加载、减少动画、跨窗口同步及不支持过渡时直接应用。

## 安装与引导

安装器采用 600×600 逻辑像素、白色背景、居中品牌、两行路径和深色主按钮；支持 DPI 缩放。首次 Profile 页以两个圆角卡片表示默认资料位置及选择/新建。

引导正文最大宽度 980px，标题 28px，说明 16px，选择卡圆角 24px、间距 16px；窗口较窄时单列。Logo 动画约 800ms，页面切换 160ms；减少动画时显示静态状态。监测和供应商 Key 可独立跳过，按 Profile 保存引导进度。

资料占用饼图只展示互斥的磁盘文件分类；数据库内部载荷、压缩前字节及内存缓存不参与合计。保留字节数、图例、百分比、键盘焦点和空状态。

## 参考、来源与复用

- DeepSeek Harness（MIT）：`apps/desktop/installer/pages.nsh`、`drawing.nsh`、`theme.nsh` 和 `lifecycle.nsh`；原生 GDI+ 圆角绘制适配在 `desktop/installer-drawing.nsh`，不引入其更新、卸载或资料协议。
- 开屏布局参考 `packages/client/ui-settings-account/src/client/DesktopOnboarding.module.css` 与 `DesktopOnboarding.tsx`；采用灵犀现有组件及 Profile 接口，不引入 DSH 账户、凭据或遥测实现。
- 官方仓库：https://github.com/deepseek-ai/deepseek-harness 。许可证保留在 `static/vendor/dsh/LICENSE`。
- 项目内部组件库 `static/ui-kit.html` 提供实际共享样式、标识、选择卡和灰色导航样例。新增界面优先使用这些令牌和组件。

顶栏左侧依次为后退、前进、侧边栏、文件、编辑、视图、帮助和主题切换，桌面右侧为原生三个窗口控件。主框采用 18px 圆角；总览移除嵌套灰色容器，白色模块卡片保留。安装路径与选择按钮使用白色圆角及灰影，立即安装使用黑底白字圆角按钮，实际进度为蓝色圆角。
