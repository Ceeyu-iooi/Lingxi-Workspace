# 灵犀设计规范

当前唯一设计依据为根目录 `design.md`。浅色与深色实例分别见 `/preview.html`、`/preview-dark.html`。修改业务界面时同步更新规范与预览。

六套主题在外观设置中选择，并应用到当前 Profile 的全部界面。视觉套件与主题套件固定采用横向陈列，底部圆点和透明侧边箭头导航，支持拖动及键盘，滚轮只滚动页面。窄屏保留左侧图标栏，页面缩放与字号设置分别处理；表格切换只更新数据，不改变行列位置。

主应用顶栏与侧栏共用主题填充色；独立 preview、计价与规范只继承浅／深模式，浅色导航白色、深色导航与正文一起使用默认雾蓝深色样式，正文及卡片保持中性表面。来源与模型明细、最近请求的 JellyRadio 与容器顶部和右侧保持 18px 内边距；窄屏在标题下方靠右排列，保留同样的外侧留白。


共享状态由应用外壳管理：每次冷启动宽窗口直接展开侧栏，运行内切页、辅助窗口及托盘恢复保留状态。缩放只有一个写入口，设置、快捷键与重置共用，按Profile保存。主体四角18px，四周12px主题底色间隙。

规范目录支持原生滚动并隐藏滚动条。按钮、导航、页签与装饰文字不可选取，输入、正文及可复制数据保持正常选取；JellyRadio实心选中使用强调色与白字。浮层位置按实际渲染层几何换算，不能使用旧缩放变量补偏移。

帮助菜单的资源管理器采用CPU、内存、存储、网络四页大弹窗。可见指标页每2秒采样，存储按需扫描，网络限1000条/2MiB并脱敏；关闭释放。共享缓存与进程内存不相加。更新启动检查一次，日志区域280px内部滚动，下载显示真实百分比与已下载MB/总MB；取消、重试、校验和确认安装分开。
